# Ocean Strike

## Что исправлено в этой версии
- Регистрация нового пользователя теперь запрашивает **логин, электронную почту и пароль**.
- При запуске `index.html` напрямую регистрация работает локально в браузере.
- При запуске через Node.js/Express регистрация хранится в SQLite; email привязан к аккаунту.
- Локальный профиль теперь хранит **историю завершённых партий и статистику**.
- Серверная версия хранит историю партий в базе данных и позволяет получать её после входа.
- Игровая логика, AI, радар и правила игры не изменялись в рамках этого исправления.

## Локальная проверка
Можно открыть `index.html` напрямую. Это режим проверки на одном устройстве.

## Полная версия с сервером
Нужен Node.js 20+.

```bash
npm install
npm start
```

Затем открыть `http://localhost:3000`.

Для публикации в интернете сервер нужно разместить на хостинге с постоянным хранилищем SQLite или заменить SQLite на управляемую базу данных.
